# 🌱 Spring Plant Monitor

라즈베리파이와 DHT11 센서를 이용해 **온도와 습도를 측정하고 서버로 전송하는 IoT 프로젝트**

---

## 📦 Project Overview

이 프로젝트는 다음과 같은 구조로 동작한다.

Raspberry Pi  
↓  
Python Sensor Script  
↓  
Spring Boot Server  
↓  
Database 저장  

식물의 환경 데이터를 수집하여 관리하는 **IoT Plant Monitoring System**이다.

---

## 🛠 Tech Stack

### Hardware
- Raspberry Pi
- DHT11 Temperature / Humidity Sensor

### Software
- Python
- Spring Boot
- Git / GitHub
